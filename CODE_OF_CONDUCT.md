# Code of conduct

AshLight is a small, unofficial companion for Path of Exile 2. This page sets
out how we treat each other in its issues, pull requests and discussions.

## Expected

- Be respectful. Assume good intent, keep criticism about the work, and
  welcome newcomers.
- Stay on topic: AshLight, its code, its docs and how players use it.
- Keep reports useful and safe: share only what the bug form asks for, and
  never post game files, account details or anyone's private information.

## Not accepted

- Harassment of any kind: insults, personal attacks, threats, slurs,
  unwanted attention, or posting someone else's private information.
- Spam, advertising, or off-topic arguments that drown out real reports.
- Requests for features that break the game's rules or AshLight's floor (see
  "What AshLight never does" in the README): reading or writing game memory,
  sending input to the game, macros, watching the clipboard or the screen,
  modifying game files, or calling undocumented game endpoints. Such requests
  are closed without debate.

## What the maintainer may do

The maintainer may edit, hide or delete comments, close or lock issues and
pull requests, and block accounts that break this code. Most cases end with a
short note and a hidden comment.

## Reporting

Report a problem privately through the repository's Security tab: use the
"Report a vulnerability" button to open a private report and say that it is a
conduct report. Do not report conduct in a public issue. Reports are read by
the maintainer only and kept private.
