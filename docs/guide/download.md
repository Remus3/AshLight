# Download

AshLight is a free companion for Path of Exile 2 on Windows. It runs on your
own computer and only reads; it never touches the game.

## Is there a release?

No release yet. Until the first release ships, you install AshLight from its
source code: a copy of the AshLight repository on your computer. There is no
installer file to download and nothing to pay for.

AshLight releases appear at github.com/Remus3/AshLight/releases.

## What you need

- Windows 10 or 11.
- Python 3.11 or newer. For a new install take 3.13 or newer: python.org no
  longer offers a Windows installer for 3.11 or 3.12.
- Node.js 22.12.0 or newer, only if you want the desktop client and the
  in-game overlay. Without it you still get the dashboard in your browser.
- Path of Exile 2 from Steam, played in Windowed Fullscreen if you want the
  overlay on top of the game.

## Install from source

1. Get a copy of the AshLight source code onto your computer (clone the
   repository with git, or download its source archive and unpack it).
2. Open PowerShell in that folder and run the one setup command from the
   [Quick start](quick-start.md).
3. Start AshLight from the "AshLight" shortcut that setup puts in the Start
   Menu and on the desktop.

Setup is safe to run again: a finished step is skipped and your settings are
kept. To update later, quit AshLight, get the newer source, run setup again
and start it from the shortcut.

## What you do not need

- No game account login, password or session cookie. AshLight never asks.
- No internet connection for the live log features. Prices and game data need
  the "Use web data" switch, which is off until you turn it on.
