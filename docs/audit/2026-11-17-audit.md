## Fixed (medium)

### F1 - held item-check hotkey could read the clipboard many times per press (medium, ToS floor robustness)

- Where: app/eval_hotkey.js createEvalHotkey (before the fix: only a
  `busy` flag while a POST is in flight).
- Evidence: Electron globalShortcut on Windows is RegisterHotKey; a held
  key re-fires through keyboard auto-repeat (first repeat after 250-1000
  ms, then about every 30 ms). The busy flag clears after each local POST
  (milliseconds), so holding Alt+Shift+E produced a clipboard read about
  every 30 ms. Decision 0003: "read ONLY once per manual key press". Not a
  confirmed violation in play (no one has held the key), but nothing in
  the code prevented it.
- Fix: a sliding REPEAT_GAP_MS = 1200 window (longer than the 1000 ms
  maximum Windows repeat delay): every event within the gap of the previous
  event, ignored ones included, is the same press. No timer, no watcher.
- Regression tests: app/test/eval.test.js "a held key (auto-repeat) reads
  the clipboard once" (100 repeats -> 1 read; release + press -> 2) and
  "without an injected clock it still guards repeats".

### F2 - commit messages were never leak-swept before push; no history mode (medium, hygiene)

- Where: tools/leak_sweep.py main (modes --tree, --staged, --pre-push
  only); .githooks/commit-msg ran only fleet_identity.
- Evidence: a message leak survived until the first push, and the repo has
  no remote (pre-push refuses every push), so it was never swept at all.
  There was no way to sweep the full history on demand.
- Fix: `--message FILE` (git's '#' lines skipped) called from commit-msg
  after the identity strip; `--history` sweeps every commit's added lines,
  paths and message (`git rev-list --all`). Full history at audit time:
  ARMED needles=22, 0 findings, rc 0.
- Regression tests: tests/test_leak_sweep.py
  test_message_mode_scans_message_skips_comments,
  test_message_mode_cli_exit_codes,
  test_history_mode_finds_leak_in_old_commit_and_message (a needle added
  then scrubbed is still found), test_history_mode_clean_repo,
  test_commit_msg_hook_runs_the_message_sweep.

### C1 - TC-CODE-REAL flipped done without its ACCEPT (medium, correctness)
