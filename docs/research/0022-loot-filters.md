# 0022 - Loot filters within the floor

All sources accessed 2026-11-17. Question: can AshLight help with PoE2
item filters without touching the game or its files? Verdict: YES, as a
user-saved file only (adjudicator ruling, section 3). Filed: UTIL-FILTER.

## 1. Facts

- GGG lists item filters as a supported file format: "Item Filters allow
  you to customise the way loot labels appear. You can edit the size,
  colour, or even hide item drops entirely"
  (https://www.pathofexile.com/developer/docs/game , accessed 2026-11-17).
  The policy page has no text about filter tools; it does say apps that
  interact with the game or its files are prohibited (0006 line 7;
  https://www.pathofexile.com/developer/docs , accessed 2026-11-17).
- Syntax: Show / Hide / Minimal blocks with conditions and actions,
  `Continue`, and `Import "<file>" Optional` (skipped when missing); some
  conditions are tagged PoE2-only (e.g. waystone tier)
  (https://www.pathofexile.com/item-filter/about , accessed 2026-11-17).
- Location: the game reads filters from the folder its in-game folder
  button opens, `%userprofile%\Documents\My Games\Path of Exile 2`, "not a
  subfolder"; "do NOT place it in the 'onlinefilters' folder"
  (https://github.com/NeverSinkDev/NeverSink-Filter-for-PoE2 , accessed
  2026-11-17).
- Account Item Filters API: `GET/POST /item-filter[/<id>]`, scope
  `account:item_filter`, `realm` accepts `poe2`
  (https://www.pathofexile.com/developer/docs/reference , accessed
  2026-11-17). OAuth only, so blocked on TC-OAUTH-REG like TC-CURX.
- Licenses (ideas only, nothing bundled): NeverSink's PoE2 filter is
  "MIT License", "Copyright (c) 2026 NeverSink"
  (https://raw.githubusercontent.com/NeverSinkDev/NeverSink-Filter-for-PoE2/master/LICENSE ,
  accessed 2026-11-17); the author asks that reused parts credit the
  source filter (https://www.pathofexile.com/forum/view-thread/3693141 ,
  search snippet, accessed 2026-11-17). Exile-UI's "FilterSpoon" in-client
  filter editor is MIT (https://github.com/Lailloken/Exile-UI , accessed
  2026-11-17). FilterBlade (web editor) is a closed website; study only.
  The filter format itself is GGG's documented syntax, not a licensed work.

## 2. What AshLight can add that NeverSink / FilterBlade do not

- Build-aware highlights: bases, weapon types and gem classes the loaded
  PoB build uses (decision 0004 inputs, already local).
- Live price tiers from the cached poe.ninja overviews AshLight already
  pulls (0019), for uniques and stackables, refreshed hourly; FilterBlade
  also economy-tiers, so this is a smaller gain.
- Design: a small AshLight-original `ashlight.filter` snippet the player
  imports from their own main filter with one `Import "ashlight.filter"
  Optional` line, so it layers on top of NeverSink without editing it.

## 3. Adjudicator ruling (2026-11-17)

Decision: generate an AshLight-original `ashlight.filter` snippet offered as
a dashboard download on the player's click; the player saves it into their
filter folder and adds the `Import` line themselves. Optionally merge into a
filter the player hands over via the browser file input, again returned as
a download. AshLight never writes into My Games.
Alternatives: (B) direct write / refresh in My Games - rejected, collides
with "never modify any game file" and GGG's "interact with the game or its
files" ban; (C) Account Item Filters API upload - documented, allowed in
principle, BLOCKED on TC-OAUTH-REG; (D) no feature - fallback.
Why: no game-file write and no input to the game; delivery is a user click,
like the Copy-code clipboard write (decision 0014); inputs are already
permitted (poe.ninja cache, loaded PoB build).
Constraints: an uploaded filter is read from the upload body only, kept in
memory, its path never stored or logged; a merged copy is a download, never
written back. Bundle no NeverSink text (if any is ever reused: MIT notice and
a decision record).
Reverses if: GGG states in writing that filter tools may not be offered or
that generated filters count as game-file modification; the operator orders
(B) in writing; GGG documents a filter-folder write as allowed. (C) is added
once the OAuth client exists.

## 4. Recommendation

YES, modest value, after the price book (done) and TC-BUILDFILE (same
"user-saved file" pattern). Row UTIL-FILTER filed. ZERO-CLICK limit: the
file is regenerated by itself; the single save is the player's placement
act, and the `Import` line is a one-time edit by the player.
