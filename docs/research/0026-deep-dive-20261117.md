## 1. GGG developer docs and policy

- Changelog newest entry is still 3.30.0 "Covens of Umbra", dated 12/11/2026
  (DD/MM): "Updated the Policy wording around macros and overlays to be
  clearer about when they apply."; PoE2 Account Leagues endpoint documented
  as enabled; new fields wickerman, variants, variantEffects, connections,
  rareonly. Then 3.29.3b (05/09/2026), 3.29.0 (21/07/2026, Currency
  Exchange public via CDN), PoE2 0.5.0 (26/05/2026, PoE2 Ladder top 1000,
  tree URL v7). No rate-limit change in any of the five newest entries
  (https://www.pathofexile.com/developer/docs/changelog).
- Overlay rules, verbatim: information "sourced from the screen, the
  clipboard, or the game's logs" may be read "as long as the user is aware of
  what you are doing with that data"; "Reading from the screen or clipboard
  may only be performed once per manual key press." Macros "must be invoked
  manually by the user (automated invocations such as but not limited to:
  timers, reacting to file changes, or from reading the screen are not
  allowed)". Standalone executables "must use a public OAuth client if
  interacting with our APIs"; registration: "We are currently unable to
  process new applications." Matches 0001 / 0024
  (https://www.pathofexile.com/developer/docs).
- Rate limits are dynamic; parse X-Rate-Limit-Policy, -Rules, -{rule} and
  -{rule}-State (`maxhits:period:restricted-seconds`) and Retry-After on 429;
  many 4xx in a short time restricts access. UA form `OAuth
  {$clientId}/{$version} (contact: {$contact})`. Reverse engineering
  endpoints outside the docs is ToU 7i (same page).
- API Reference, PoE2 realm: league, league ladder (top 1000), account
  leagues, character, item-filter, public CDN currency-exchange; stashes and
  public stashes are PoE1 only; a "Build Planner (PoE2 only)" file format is
  indexed (https://www.pathofexile.com/developer/docs/reference). No trade2
  endpoint is documented: decision 0017 stands.
- robots.txt of the PoE site disallows `/api/` and several account / forum
  paths for `*`; `/poe2` is not disallowed
  (https://www.pathofexile2.com/robots.txt). AshLight calls no
  www.pathofexile.com /api path.
