# 0018 - PoE2 patch state, Client.txt deltas, GGG policy delta (Nov 2026)

All sources accessed 2026-11-17. Extends 0001 (policy) and 0002 (log).

## Policy verdict (read first)

NO change to GGG's third-party policy that affects the ToS floor since the
0001 re-read of 2026-11-17. The latest developer-docs changelog entry is
still 3.30.0 (Covens of Umbra, 12/11/2026, "Clarified when the macro and
overlay policy applies"), already covered by 0001
(https://www.pathofexile.com/developer/docs/changelog , accessed
2026-11-17). The policy page still says: overlay reads only "as long as the
user is aware", screen / clipboard "once per manual key press", standalone
executables "must use a public OAuth client" when calling the APIs,
registration "currently unable to process new applications"
(https://www.pathofexile.com/developer/docs , accessed 2026-11-17).
No AUDIT- row is needed for a policy change. Two floor-interpretation
questions raised by documented features were ruled by an adjudicator
(section 4) and filed as rows.

## 2. Client.txt line formats

- Patch notes 0.5.0 to 0.5.5f contain NO line about Client.txt, the log
  file, whisper formats or chat commands. Only chat changes: 0.5.5 "The
  number of challenges you have completed is now displayed next to your
  name when sending a chat message" (in-game display; log effect
  UNVERIFIED) and an NPC chat-name fix in 0.5.5c
  (https://poepatchnotes.pages.dev/poe2.html , accessed 2026-11-17).
- No public source documents new PoE2 log lines for map completion, boss
  kills, item drops or currency pickups. Community trackers derive map runs
  from area transitions only: DoofDilla's PoE2 stat tracker uses
  "Automatic map transition detection through Client.txt monitoring" and
  takes loot from hotkey snapshots plus the (currently disabled) GGG
  inventory API (https://doofdilla.github.io/dillapoe2stat , accessed
  2026-11-17); Lailloken UI (MIT) reads level, "area & transitions, NPC
  dialogues" (https://github.com/Lailloken/Lailloken-UI , accessed
  2026-11-17). UNVERIFIED-negative: no drop / currency line exists; our own
  live log (0002 section 7, 365 shapes) had none.
- What can be parsed for value from lines we already know (0002):
  - Map runs: `Generating level <N> area "<id>" with seed <N>` gives the
    area id and area level of every new instance; a map id (endgame area
    ids; the exact prefix for 0.5.5 maps is UNVERIFIED, verify live) plus
    hideout / town `[SCENE]` names give map entered, map left, time in map,
    maps per hour, area level (waystone tier proxy). Re-entry into the same
    seed = same map (portal back), a new seed = new map.
  - Boss encounters: NPC dialogue lines `<NPC Name>: <text>` (0002 section
    7, no channel prefix) are written for speaking bosses; a boss-name list
    from the repoe-fork snapshot (decision 0009) could mark "boss reached".
    A kill line is NOT known; UNVERIFIED.
  - Deaths per map: `has been slain` (still NOT SEEN live, LIVE-1).
  - Session stats: `Connecting to instance server` counts instances;
    `***** LOG FILE OPENING *****` bounds a game run.
- Rule kept: unknown system lines go to the debug sink (0002 section 4) so
  new 1.0 lines show up without code changes.

## 3. GGG API Reference / Data Exports delta

- NEW to our research: the API Reference has a "Public API" Currency
  Exchange endpoint: `GET https://web.poecdn.com/api/currency-exchange[/<realm>][/<id>]`,
  realm `poe2` allowed, no scope listed; hourly digests ("purely
  historical", no current hour); `next_change_id` (unix hour), `markets`
  with `league`, `market_id`, `market_pair` (base item metadata ids),
  `volume_traded`, `lowest_stock`, `highest_stock`, `lowest_ratio`,
  `highest_ratio` (https://www.pathofexile.com/developer/docs/reference ,
  accessed 2026-11-17). Changelog: 3.29.0 (21/07/2026) "The Currency
  Exchange endpoint is now public", cached data via the CDN
  (https://www.pathofexile.com/developer/docs/changelog , accessed
  2026-11-17).
- Live check (2 GETs, truthful AshLight research User-Agent, no cookie,
  2026-11-17): no id -> 200, `{"next_change_id":1733515200,"markets":[]}`
  (first hour, Dec 2024); id = a recent hour -> 200 application/json,
  1,589,380 bytes, 1,927 markets (Forbidden Rites 1,188), `Cache-Control:
  max-age` about one year (immutable hour files). Market ids are internal
  paths such as `Metadata/Items/Currency/CurrencyModValues`; display names
  need a base-item map.
- RULED (adjudicator, 2026-11-17): AshLight does NOT call it yet. Decision:
  no Currency Exchange call without an AshLight public OAuth client.
  Alternatives: call now with an AshLight UA; fake an `OAuth <id>` UA
  (rejected, untruthful). Why: the docs require standalone executables to
  use a public OAuth client for the APIs and the UA format carries the
  client id. Reverses if: AshLight gets a public OAuth client
  (TC-OAUTH-REG) or GGG's docs exempt scope-less public endpoints in
  writing. Filed: TC-CURX (BLOCKED on TC-OAUTH-REG).
- PoE2 Ladder endpoint enabled (top 1000) since 0.5.0, scope
  `service:leagues:ladder` (OAuth; same block)
  (https://www.pathofexile.com/developer/docs/reference , accessed
  2026-11-17).
- Data Exports: unchanged; for PoE2 only the passive tree repo
  (github.com/grindinggear/poe2-skilltree-export). "We do not officially
  provide access to any in-game data outside of our supported APIs." No
  export of trade stat ids, mods or base items, so TC-UPGRADE-STATS gets
  no GGG source from here
  (https://www.pathofexile.com/developer/docs/data , accessed 2026-11-17).
- File Formats: Build Planner (PoE2 only) `*.build` JSON, "Version 1
  (Experimental)": "Some features of the game can use files that can be
  created manually or by tools"; the game watches the user's
  `Documents/My Games/Path of Exile 2/BuildPlanner` folder; Build object
  `name`, optional `author`, `link`, `description`, `ascendancy`,
  `passives` (ids like `strength89`, `level_interval`, `weapon_set`),
  `skills` (BaseItemTypes ids, `support_skills`), `inventory_slots`
  (`inventory_id`, `unique_name`), `additional_text` markup; "Meta gems
  are currently not supported"
  (https://www.pathofexile.com/developer/docs/game , accessed 2026-11-17).
- RULED (adjudicator, 2026-11-17): a `.build` file only as a user-saved
  file (download / Save-as on the player's click); the app never writes
  into the BuildPlanner folder. Alternatives: direct write (rejected:
  "never modify any game file" floor, game consumes tool output
  unprompted); no export (needlessly strict, GGG invites tool-made files).
  Reverses if: GGG explicitly permits tools to write there, or the
  operator rules a click-triggered write acceptable. Filed: TC-BUILDFILE.
