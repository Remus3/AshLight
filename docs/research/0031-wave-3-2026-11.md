# 0031 - Third wave of player value (Nov 2026)

Date 2026-11-17. Research 0020, 0023 and 0028 rows are done. This note
looks for the third wave inside the ToS floor (CLAUDE.md, decisions 0003,
0004, 0009, 0013, 0014) from three angles: what guides and companion
tools say players struggle with (campaign, waystones / atlas, crafting,
trade), what Path of Building PoE2 already exports that AshLight does not
show, and what the announced 1.0 (research 0021) lets us prepare. Ranked
8 candidates (section 4); floor cases G / H / I ruled by the adjudicator
on 2026-11-17 (section 5); top 4 filed as ROADMAP rows (section 6).
Companion tools are studied for ideas only; no code read or copied.

## 1. What players struggle with (guides and tools)

Campaign:
- Resistances at act bosses: "Many players struggle with Act 1's final
  boss if they have less than 30% to 40% Cold Resistance!"; 75 percent is
  the cap goal and 50 percent "means double damage taken"; fire before the
  Act 3 Rudja fight; named sources of +10 percent res per act (Maxroll,
  Comprehensive League Start Leveling Guide, 0.5.5, updated 2026-09-08,
  https://maxroll.gg/poe2/getting-started/comprehensive-league-start-leveling-guide ,
  accessed 2026-11-17).
- Level checkpoints the same guide asks the player to track by hand:
  flask base tiers (Medium 4, Greater 10, Grand 16, Giant 23, Colossal 30,
  Gargantuan 40, Transcendent 50, Ultimate 60) and movement-speed boots
  (15 percent from about level 16, 20 at 33, 25 at 46); the guide's own
  summary disagrees on two of these numbers, so AshLight must take base
  levels from data, not from guide text (same URL, accessed 2026-11-17).
- Beginner-mistake lists repeat "neglecting elemental resistances" and
  splitting damage across types (Vice,
  https://vice.com/en/article/path-of-exile-2-is-a-brutal-game-but-these-10-tips-should-help-ease-the-pain ;
  Sportskeeda, https://www.sportskeeda.com/mmo/path-exile-2-poe2-mistakes-to-avoid ;
  search snippets, accessed 2026-11-17).
- Levelling overlays answer "which gem to take, which supports, when to
  swap" and per-act vendor regexes: ExileXP (forum thread
  https://web.poecdn.com/forum/view-thread/3934202 ), PoE-Leveling-Overlay
  (MIT, https://poe-leveling-overlay.pages.dev/ ), XileHUD (Client.txt
  zone detection plus PoB, https://gh.hhj520.top/XileHUD/poe_overlay ),
  Exile-UI Act-Tracker (MIT, research 0023) (search snippets, accessed
  2026-11-17). AshLight already has zone notes, act splits and search
  strings; a gem-swap planner would need guide prose (decision 0009
  limits) and is not ranked.

Waystones / atlas:
- Rolling decisions: which mods to avoid (reduced recovery, reduced flask
  charges, negative max res, monster ailment / stun boosts), which reward
  mods matter (item quantity, rare monsters, then rarity, magic monsters),
  Vaal outcomes (four 25 percent branches), unidentified waystones giving
  +30 percent waystone drop chance instead of quantity, boss always drops
  a waystone one tier higher (Maxroll, Rolling Waystones and Precursor
  Tablets, 0.2.0 era, page updated 2026-05-11,
  https://maxroll.gg/poe2/resources/rolling-waystones-and-precursor-tablets ,
  accessed 2026-11-17). UTIL-WAYSTONE covers the risk side only.
- Tablet slot count by waystone mod count (0-2: 1, 3-5: 2, 6+: 3) and
  towers decoupled from tablets in 0.3.1 (Mobalytics,
  https://mobalytics.gg/poe-2/guides/towers-and-tablets ; PC Gamer,
  https://www.pcgamer.com/games/rpg/path-of-exile-2-is-making-a-surprise-atlas-overhaul-next-week-to-liberate-its-players-from-tower-tyranny ;
  search snippets, accessed 2026-11-17). 0.5 rebuilt the atlas again
  (PCGamesN, https://www.pcgamesn.com/path-of-exile-2/patch-0-5-return-of-the-ancients-endgame-rework ,
  search snippet, accessed 2026-11-17), so tablet rules are UNVERIFIED for
  the current patch and are not used.

Crafting:
- Guides describe a Transmute / Augment / Regal / Exalt ladder, essences
  that guarantee a modifier, omens as meta-modifiers, and 0.5 forbidding
  more than one essence modifier per item (Mobalytics 0.3 crafting
  changes, https://mobalytics.gg/poe-2/guides/0-3-crafting-changes ;
  Mobalytics essence guide,
  https://mobalytics.gg/poe-2/profile/lolcohol/guides/essence-guide-poe-2 ;
  Maxroll crafting overview,
  https://maxroll.gg/poe2/resources/path-of-exile-2-crafting-overview ;
  search snippets, accessed 2026-11-17). No source answers "which currency
  next on this item"; the player has to count open prefixes / suffixes.
  The game's own Ctrl+Alt+C text names each mod's Prefix / Suffix and Tier
  (research 0003 section 2; item.Mod.kind already parses it).

Trade: AshLight already prices uniques / stackables, builds trade links,
watches prices and lists movers (research 0020, 0028). Nothing new under
the floor ranked above the items below (rare pricing would need the trade
API, decision 0017).

## 2. What PoB-PoE2 exports that AshLight does not show

Source: the hash-pinned PoB-PoE2 checkout in the AL sidecar cache
(config/tc_pins.json, commit 7d6f530c), read 2026-11-17. Stat names
only, no code copied (MIT).
- Skill DPS split: Build.lua writes one `<FullDPSSkill stat=... value=...
  skillPart=... source=...>` element per contributing skill into the
  build XML (Build.lua, PlayerStat save loop, `FullDPSSkill`). It is in
  every saved build, so it works with the calc component off. AshLight
  does not parse it (no hit in server/, web/, tests/).
- Ailment DPS split: `BleedDPS`, `IgniteDPS`, `PoisonDPS`, `ImpaleDPS`,
  `TotalDotDPS`, `CombinedDPS` (BuildDisplayStats.lua lines 43-72).
  calcwire.DPS_KEYS uses only the first present of FullDPS / CombinedDPS
  / TotalDPS / TotalDotDPS.
- PoB warnings not yet mirrored by MATH-BUILD-HEALTH: unreserved Life
  `<= 0`, unreserved Mana `< 0`, accuracy below Life with Precise
  Technique, and DoT DPS at or above the in-game cap (`data.misc.DotDpsCap`)
  (BuildDisplayStats.lua warnFunc entries, 22 in total).
- Ailment / stun defence: `IgniteAvoidChance`, `PoisonAvoidChance`, per-
  ailment `<Ailment>AvoidChance`, `StunThreshold`, `StunAvoidChance`,
  `StunDuration`, `CurseAvoidChance`, `SilenceAvoidChance`
  (CalcDefence.lua around lines 1950-1990 and 2555-2620). These are
  calc outputs (bridge `outputs`, calc on), not all PlayerStat entries.
- Flask / charm: `FlaskEffect`, `FlaskChargeGen`, `LifeFlaskChargeGen`,
  `ManaFlaskChargeGen`, `CharmEffect`, `CharmLimit`, `EmptyCharms`
  (CalcPerform.lua). PoB exposes no "flask uptime" output; an uptime
  number would be AshLight math and is out (decision 0004).
- Cost / sustain: `ManaPerSecondCost`, `ManaRegenRecovery`,
  `NetManaRegen`, `LifeLeechGainRate` (BuildDisplayStats.lua lines
  80-157). Shown as PoB's values; no own "sustainable" verdict beyond
  PoB's own NetManaRegen sign.

## 3. 1.0 (2026-12-11) - what we can prepare

From research 0021 (no 1.0 patch notes yet; a 2026-11-17 search found
none): Acts 5-6, Duelist / Shadow, the Conquerors of Wraeclast siege
league, a passive-tree overhaul and a free-to-play influx. UTIL-1.0-POST
and DOC-1.0-RUNBOOK already hold the parser / data checklist. What this
wave adds: campaign checks (item 3 below) are most valuable exactly when
F2P newcomers arrive, and the data-driven design (base levels from the
repoe-fork snapshot, resists from PoB) needs only a snapshot refresh for
Acts 5-6, no new authored numbers. Boss-element one-liners for Acts 5-6
wait for the patch notes and a live log.

## 4. Ranked candidates

1. Skill and ailment DPS split (MATH-SKILL-SPLIT). One row per
   FullDPSSkill (name, count, DPS, share of total) plus the ailment DPS
   lines when non-zero; "from PoB". Floor: YES - PoB's own outputs from
   the user-pasted build (decision 0004), no recompute. Data: PoB build
   XML (calc off) and bridge outputs (calc on). Size: small (parser +
   card). Value: high; answers "which skill actually does my damage" and
   catches the split-damage beginner mistake.
2. Defence breakdown and remaining PoB warnings (MATH-DEF-BREAKDOWN).
   Add PoB's remaining warn conditions (unreserved life / mana, accuracy,
   DoT cap) to the health card, and a compact defence list: ailment avoid
   chances, stun threshold / avoid, flask and charm charge gen, mana cost
   per second vs regen, all as PoB values. Floor: YES - same as
   MATH-BUILD-HEALTH ruling A (research 0028). Data: PoB outputs (calc on
   for the CalcDefence values; hidden when off). Size: small-medium.
   Value: high; PoB users read these in PoB's sidebar, others never see
   them.
3. Waystone reward summary (UTIL-WAYSTONE-REWARD). On the same waystone
   press, sum the reward mods (item quantity, item rarity, pack size,
   rare / magic monsters, waystone drop chance) next to the existing
   risk line: "Rewards: +38% quantity, +25% rare monsters. Risky: ...".
   Floor: YES - the per-press clipboard text only (decision 0003).
   Data: hotkey item text. Size: small (rules on mod text, like
   waystone.py). Value: high; every map is rolled and the player weighs
   risk against reward on every one. Tablet slot rules are left out
   (UNVERIFIED after 0.5).
4. Campaign level checks (UTIL-CAMPAIGN-CHECKS). From player level
   (Client.txt) and the loaded PoB build: "a higher flask base is
   available at your level" (base drop levels from the build-time
   repoe-fork base_items snapshot vs the build's equipped flasks), boots
   without movement speed past a level setting, and, on entering a known
   boss zone, the build's resist for that boss's main element (AshLight-
   authored one-liner, restated fact). Floor: OK WITH CONDITION (ruling
   H). Data: Client.txt + PoB outputs + build-time snapshot. Size:
   medium. Value: high for 1.0 F2P newcomers; the guide's own numbers
   are inconsistent, the data is not.
5. Affix slots and next currency (UTIL-CRAFT-SLOTS). On the item press,
   with advanced (Ctrl+Alt+C) text: open prefixes / suffixes, mod tiers,
   and which basic currencies can act on the item with their cached
   price. Floor: YES (ruling G). Data: hotkey item text + cached
   poe.ninja (web_data on). Size: medium. Value: medium-high; but rule
   text must track crafting changes every patch (0.3, 0.5 both changed
   essences), so maintenance cost is real. Listed, not filed this wave.
6. Atlas progress (UTIL-ATLAS-PROGRESS). Towers / citadels / map bosses
   run, from area ids in the log, kept in a small local history. Floor:
   YES (ruling I). Data: Client.txt. Size: medium. Value: medium; the
   endgame area ids are UNVERIFIED and 1.0 changes the atlas again.
   Not filed until a live endgame log exists (LIVE-1 / UTIL-1.0-POST).
7. Acts 5-6 campaign data (part of UTIL-1.0-POST). Boss-element lines and
   zone notes for the new acts. Floor: YES. Data: patch notes + live log +
   snapshot refresh. Size: small. Value: high on launch day but BLOCKED on
   1.0 patch notes; folded into UTIL-1.0-POST, not a new row.
8. Gem swap planner (levelling overlays' main feature). Floor: YES in
   principle, but it needs per-build guide prose (decision 0009 forbids
   bundling poe2db / wiki text) or the player's own PoB skill sets per
   level (PoB has no level-gated skill sets). Value: medium. Not filed.

Not feasible under the floor: rare-item pricing (trade API, decision
0017), tablet / atlas state read from the game UI (screen watcher,
decision 0003), drop tracking (no log line, research 0020).

## 5. Adjudicator rulings (2026-11-17)

- G | floor-ok | per-press clipboard text only; prices from the cached
  poe.ninja book only while web_data is on, shown as unavailable when off;
  no trade2 call; AshLight-authored rule text; nothing sent to the game.
- H | floor-ok-with-condition | opted-in Client.txt, the loaded PoB build
  text and the repoe-fork snapshot only; the snapshot is a build-time
  fetch into the sidecar cache with attribution (decision 0009), none of
  its data in tracked files; boss-element lines are restated facts, no
  copied guide text, guide sources credited in docs only; no screen or
  memory read.
- I | floor-ok | "Generating level N area <id>" lines only; history in
  gitignored ops/runtime; ids from live log fixtures; passive tail, no new
  watcher, no input.
