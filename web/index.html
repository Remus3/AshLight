                  What AshLight does and never does

                  AshLight does

                  • Read the game's log file, Client.txt, only after you allow it on this page. The word at the top says when it is reading.
                  • Read the clipboard once each time you press the item check hotkey, and at no other time.
                  • Copy text to your clipboard only when you click a Copy button.
                  • Fetch prices from poe.ninja, and open a build link you paste, only when you turn on web data.
                  • Run on this computer only. This page can't be opened from another device.

                  AshLight never

                  • Sends a key press, click or chat message to the game.
                  • Reads or changes the game's memory or network traffic, or changes any game file.
                  • Writes into your game folders.
                  • Asks for your account, password or login cookie.
