                            Loot filter add-on

                            A small add-on for your own loot filter. It shows rare drops of the item bases your build wears in larger text. The button sends ashlight.filter to your browser's downloads. Move it yourself to the folder the game's own filter button opens. Then add this line near the top of your own filter:

                            Import "ashlight.filter" Optional

                            AshLight writes nothing into your game folders. You move the file, and you can delete it at any time.

                            Or add it to your own filter: pick your filter file. AshLight puts its blocks at the top, hides nothing and leaves the rest as it is. Your browser saves the combined copy as a new file; your own file is not changed.

                            Prices and web data

                            Off unless you turn it on. When on, AshLight asks for two things only. It fetches currency and item prices from poe.ninja about once an hour. It opens a build link you paste, once. It never asks the trade site anything; the trade link after an item check opens only when you click it. It sends no account, password or cookie, and never touches the game.

                                            What AshLight does and never does

                                            AshLight does

                                            • Read the game's log file, Client.txt, only after you allow it on this page. The pill at the top says when it is reading.
                                            • Read the clipboard once each time you press the item check hotkey, and at no other time.
                                            • Copy text to your clipboard only when you click a Copy button.
                                            • Fetch prices from poe.ninja, and open a build link you paste, only when you turn on web data.
                                            • Run on this computer only. This page can't be opened from another device.

                                            AshLight never

                                            • Sends a key press, click or chat message to the game.
                                            • Reads or changes the game's memory or network traffic, or changes any game file.
                                            • Writes into your game folders.
                                            • Asks for your account, password or login cookie.
